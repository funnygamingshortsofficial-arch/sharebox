ShareBox

Share files with a link · Persistent + temporary

A simple starting point for your bigger file-sharing project. Connect your own Supabase project to enable real uploads.

1. Connect storage

Paste your Supabase Project URL and anon/public key. These are designed for browser use when your database/storage policies are configured correctly. Never paste a service-role key here.

2. Upload a file

Temporary links are signed links that expire after 24 hours. Persistent links remain available until you delete the file or change storage settings.

Before first use

In Supabase, create a Storage bucket named shared-files. For the quick prototype, set the bucket to public if you need persistent public links. Temporary links use signed URLs. Do not upload private or sensitive files to a public bucket.

This starter does not yet include user accounts, file management, quotas, malware scanning, or automatic deletion of old temporary uploads. Those are next-stage features for a production-grade service.
